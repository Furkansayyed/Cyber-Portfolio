## 🎯 About the Portfolio

This portfolio is designed with a **Cyberpunk / Glassmorphic / Dark Hacker** aesthetic to reflect my passion for offensive security. It serves as a centralized hub for my:
- 🛡️ **Penetration Testing & VAPT Engagements**
- 🚩 **CTF Writeups & Exploitation Labs (TryHackMe Top 1%)**
- 📜 **Published Research (Quantum Authentication & PQC)**
- 🎓 **Certifications & Professional Credentials** (OSCP Candidate, Cisco, EC-Council)

## ✨ Features

- **Immersive Cyberpunk UI/UX:** Built with a custom neon-green/cyan design language (`#00ff88`, `#00ccff`, `#ff2a6d`) with a dynamic terminal aesthetic.
- **Interactive Certificate Modals:** Click on any certification card to instantly preview the actual validated PDF document directly within an embedded viewer—no external links needed!
- **Responsive Layout:** fully functional and visually striking across all devices (Desktop, Tablet, Mobile).
- **Smooth Animations:** Includes typewriter effects, interactive hover states, glassmorphism containers, and dynamic scrolling navigation.

## 🚀 Running Locally

To run this portfolio on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/furkan-portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd furkan-portfolio
   ```
3. **Launch a local server:**
   - Using Python:
     ```bash
     python -m http.server 8000
     ```
   - Using Node.js (Live Server):
     ```bash
     npx live-server
     ```
4. **Open your browser** and navigate to `http://localhost:8000`
